# ParkingPulse LK

A smart parking solution project for Sri Lanka.

## Project Structure

```
parkingpulse-lk/
├── frontend/    # React + Vite frontend
├── backend/     # Node.js + Express API server
└── docs/        # Project documentation
```

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

## Tech Stack

- **Frontend:** React, Vite, React Router, CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas with Mongoose (planned)
